#邻里通 - 社区生活服务系统

## 项目简介
基于微信小程序的社区生活服务系统，为居民、商户和管理员提供一站式服务平台。

## 技术栈
- **后端**: Spring Boot 2.7 + MyBatis Plus + MySQL 8.0 + Redis
- **前端**: 微信小程序原生框架

## 功能模块
1. **用户角色管理**: 居民、商户、管理员三种角色
2. **社区服务展示与预约**: 便民服务分类、搜索、预约
3. **订单与交易管理**: 订单流程、支付、评价
4. **商户结算与管理**: 商户入驻、提现、统计
5. **社区互动与信息发布**: 邻里圈、公告、活动

## 环境要求
- JDK 1.8+
- MySQL 8.0+
- Redis 6.0+
- Maven 3.6+
- 微信开发者工具

## 快速开始
1. 创建数据库 `neighborhood`
2. 导入 `neighborhood.sql`
3. 修改 `application.yml` 数据库配置
4. 运行 `NeighborhoodApplication.java`

## 数据库
数据库文件位于项目根目录 `neighborhood.sql`
